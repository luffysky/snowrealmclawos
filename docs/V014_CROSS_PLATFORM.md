# ClawOS v0.14 — Cross-platform UI foundation

- Existing API, tasks, chat, marketplace demo and Creator Studio preview preserved.
- Desktop and mobile responsive liquid glass layout.
- SnowRealm horizon artwork packaged as local WebP asset.
- Per-browser theme customization with presets, user-uploaded local wallpaper, opacity, blur and accent.
- User wallpaper stored in browser localStorage only; no cloud sync or tenant theme storage yet.
- Native Expo and Tauri binaries are not yet implemented. This release is a responsive Web foundation, not a native app.
- No claims of production auth or database connectivity.
