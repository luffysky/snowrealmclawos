# ClawOS v0.18 legacy source import
The v0.18 Web UI, API, tests and historical Supabase SQL have been imported for engineering reference.
The deployed Vercel static preview (`public/index.html`) and protected Neon health API (`api/db-health.js`) are NOT replaced.
The legacy API uses unsafe single-user demo authentication and is NOT enabled in production.
The historical Supabase SQL is NOT compatible with Neon; do not execute it in Neon.
